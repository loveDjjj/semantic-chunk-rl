# VBench 实验结果

本页是 2026-11-25 核对的**历史结果摘要**。教师 SFT + 4B 整计划联合 RL 没有可报告的 VBench 测量点。历史原始输出已清理，仓库不提供逐视频结果供重算。

当前配方从 Qwen3.5-4B 两轮教师 SFT 的 LoRA 开始，不读取下面的历史 RL 断点。该 adapter 权重的 SHA-256 为 `589376508f48a1116aeab3b2c162f14b1b6e27dff2f0bc720a70d0909db22bd1`；权重不随 Git 分发。

以下比较使用普通 VBench 的固定 10% 子集：16 维、95 个不同 prompt、635 个生成任务。不是完整榜单，也不是 VBench-Long。表内分数是官方聚合值乘 100；差值从未舍入的分数计算，单位为百分点。

## 原生与分段

**无 planner** 的原生 LongLive-1.3B 固定 81 帧、5.06 秒，质量 **83.78**、语义 **69.57**、总分 **80.94**。下面所有行都保留 planner 给出的文字、段边界和长度，不是这个无分段基线。1.7B、4B、9B 是 planner 大小，并非视频骨干大小。LongLive-2.0-5B + Wan2.2 只有 61 帧推理冒烟记录，没有同协议 VBench 分数。

每行匹配 plan、视频 seed、帧数与 executor，只比较段内联合去噪和每个 chunk 单独去噪。最后一列为**逐 chunk 减联合**，方括号是按 prompt 配对 bootstrap 的总分 95% 区间。

| Planner + LongLive-1.3B | 联合：质量 / 语义 / 总分 | 逐 chunk：质量 / 语义 / 总分 | 总分差 [95% 区间] |
|---|---:|---:|---:|
| 1.7B 历史参考，非 CK250 | 85.88 / 71.03 / 82.91 | 84.42 / 71.50 / 81.84 | −1.07 [−1.78, −0.41] |
| 原始 4B，无 SFT | 84.82 / 75.71 / 83.00 | 84.17 / 75.81 / 82.50 | −0.50 [不可估] |
| 原始 9B，无 SFT | 85.34 / 76.50 / 83.57 | 84.67 / 77.65 / 83.27 | −0.31 [−1.24, +0.52] |
| GPT Sol，low | 85.29 / 78.89 / 84.01 | 85.80 / 78.48 / 84.34 | +0.33 [−0.70, +1.37] |
| GPT Astra，low | 84.95 / 77.75 / 83.51 | 85.21 / 79.28 / 84.03 | +0.51 [−0.65, +1.87] |
| 历史 1.7B 联合 RL，CK250 | 86.20 / 75.12 / 83.98 | 85.10 / 73.96 / 82.87 | −1.11 [−2.03, −0.30] |

- 三个本地参考 planner 改为逐 chunk 后均为质量分降、语义分升；历史 CK250 两项都降。总分区间仅历史 1.7B 参考和 CK250 完全低于零。Sol、Astra 的上升仍与零差异相容；4B 的 joint 归档只有汇总，不能估区间。
- [事后报告实现](../src/evaluation/paired.py)对同一 prompt 的所有 seed 和相关维度使用同一抽样次数，重抽 10,000 次。每臂保留自己实际计分的视频、帧对或帧数及官方归一化权重；这是**包含静态过滤和颜色检测差异的系统对照**，不是仅取两臂成功视频的交集。某次抽样中必需维度没有分母，该次不计入相应区间，报告列出有效次数。不将 635 条任务视作独立样本，未校正多重比较。
- 前五组每段均只有一个 chunk 的负对照合计 436 条，latent 哈希 436/436 一致。跨系统并非仅变模型参数量：历史 1.7B 参考有旧 adapter，GPT 有额外单场景指令，API 采样也不受本地 seed 控制；本表不能证明模型越大越好。

## RL 轨迹

这里是**段内联合去噪**的训练轨迹。旧 1.7B 同时更新 planner 和 executor，4B 只更新 planner、冻结原生 LongLive 和裁判；新教师 SFT + 4B 联合 RL 没有测量点。两条旧线不能互当处理组和对照组，各点差异也没有使用上表的区间作检验。

| 1.7B 旧联合训练 | 质量 / 语义 / 总分 | 4B 旧 planner-only | 质量 / 语义 / 总分 |
|---|---:|---|---:|
| 历史参考 | 85.88 / 71.03 / 82.91 | 原始 4B，无 SFT | 84.82 / 75.71 / 83.00 |
| CK100 | 85.13 / 72.10 / 82.52 | SFT，RL step 0 | 84.51 / 74.91 / 82.59 |
| CK134 | 85.42 / 72.48 / 82.83 | CK50 | 84.19 / 75.25 / 82.40 |
| CK150 | 85.79 / 73.72 / 83.38 | CK100 | 84.30 / 74.55 / 82.35 |
| CK200 | 85.95 / 73.62 / 83.49 | CK150 | 84.62 / 74.99 / 82.69 |
| CK250 | 86.20 / 75.12 / 83.98 | CK200 | 84.40 / 74.37 / 82.39 |
| CK300 | 85.42 / 72.67 / 82.87 | 205 已排空 | 未评测 |

旧 1.7B 在 CK250 曾超过参考，CK300 基本回到起点。4B 已测各点均未超过原始无 SFT 的 4B；相对 SFT 起点也无持续提升。局限之一是时长由 planner 决定：4B 原始 / SFT / CK200 平均分别为 3.16 / 7.10 / 6.84 秒；旧 1.7B 参考 / CK250 为 14.16 / 6.69 秒。不能把自由时长和固定 81 帧的差异都归为分段或 RL 的收益。下一轮应同时报告自由时长和匹配时长的实验，在独立留出集上检验；机制分析见[奖励与模型更新审计](methods.md)。

## 复算边界

抽查 8 个历史运行：各自的 `inputs/tasks.json` 字节相同（SHA-256 前缀 `152dafe2123f26a3af73`），`inputs/metadata.json` 也相同（`7e54807620a037cb544c`）。这能说明抽查的实验使用相同输入，不能证明所有比较的产物或分数相同。

只有汇总分不能重建配对区间。新实验需要同时保存按 prompt 的配对关系、plan、seed、分维度评分和覆盖数，才能复核变化来自哪里。对当前教师 SFT，600 条官方提示词进入了教师数据（含训练和内部验证集）；后续报告 VBench 结果应披露重合，不作为完全未见提示词上的泛化证据。
