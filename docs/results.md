## 登记规则

1. 实验 ID 用 `YYYYMMDD-<套件>-<范围>-<对照>-vN`（UTC 日期、小写英文和短横线）；记录放在 `docs/experiments/<实验ID>.md`。运行目录沿用同一 ID，将组别或尝试编号单列。改权重、任务或协议时新建版本，不覆盖旧记录。
2. [VBench 运行手册](vbench.md)维护通用操作。实验记录维护本次问题、两组差异、Git commit、真实运行目录及输入摘要、卡布局、UTC 开始/结束时间、失败原因和报告位置；大文件、视频和逐项收据留在共享盘。
3. 只有覆盖和报告均验收后才填总表。VBench 按每组官方报告记录质量、语义、总分及其覆盖；单个维度缺失不能填零或称为全量。跨协议、不同任务集的分数不直接相减。
